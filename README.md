# WowVoice — русская озвучка квестов для World of Warcraft

Нейросетевые голоса читают текст заданий: заголовок, описание при взятии, прогресс и завершение. У каждой расы и ключевых героев — свой голос.

## Скачать

## Установка

1. Скачай ZIP своей эпохи из [Releases](https://github.com/HappyDridex/wowvoice/releases).
2. Распакуй.
3. Скопируй **обе** папки — `WowVoice` и `WowVoiceSounds` — в `Interface\AddOns\` твоего клиента.
4. Перезапусти игру, на экране выбора персонажа включи оба аддона в списке **AddOns**.

Возьми квест — озвучка запустится сама.
